# Refinamento de UX e operação

Os dashboards cliente e empresa receberam hierarquia visual mais clara, atualização indicada, skeletons de carregamento, mensagens de erro orientativas e estados vazios com próxima ação. O dashboard empresarial usa `staleTime` curto para evitar consultas repetidas durante o expediente; nenhuma métrica nova ou dado fictício foi criado.

O fluxo mantém o operador ativo, Realtime e a decisão de navegação externa por Google Maps/Apple Maps/Waze. Não houve alteração de banco, autenticação, RLS, Edge Functions ou regras de negócio.
